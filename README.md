# Fold

A browser-only Vite, React, TypeScript, and shadcn/ui app for designing
notebook pages and imposing them onto folded ISO A-series or US paper sheets.

## Run

```sh
npm install
npm run dev
```

## Check

```sh
npm test
npm run build
```

To export, select **Export / print PDF**, then choose **Save as PDF**, actual
size, double-sided printing, and short-edge flipping in the browser dialog.
